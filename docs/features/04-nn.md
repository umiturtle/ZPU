# ニューラルネット層（`nn`）

## 使い方

```zig
// 層
const h = try zpu.nn.dense(x, w, b);                     // x @ w + b
const n = try zpu.nn.layerNorm(x, scale, bias, 1e-5, -1);
const r = try zpu.nn.rmsNorm(x, scale, 1e-5, -1);
const a = try zpu.nn.gelu(x);                            // silu / leakyRelu / relu など
const s = try zpu.nn.softmax(x, -1);
const e = try zpu.nn.embedding(table, ids);

// 損失
const l1 = try zpu.nn.mse(pred, target);
const l2 = try zpu.nn.softmaxCrossEntropy(logits, one_hot_labels);
const l3 = try zpu.nn.sparseCrossEntropy(logits, class_index);
const l4 = try zpu.nn.binaryCrossEntropyWithLogits(logits, target);

// 画像系
const c = try zpu.nn.conv2d(x, kernel, 1, 1);            // NCHW, stride, padding
const p = try zpu.nn.maxPool2d(x, 2);
const q = try zpu.nn.avgPool2d(x, 2);
const idx = try zpu.nn.oneHot(classes, depth, .f32);

// 乱数を使う層（training=false なら恒等）
var gen = zpu.rng.Rng.init(42);
const d = try zpu.nn.dropout(x, 0.5, &gen, training);
```

## 実装意図

* **合成で書く。** `conv2d` は `pad` → `sliceRanges`（stride ぶんの間引き）→
  `reshape` → `transpose` → `matmul` の合成で、専用カーネルを持たない。
  そのぶん遅い（ベンチで測れる）が、**逆伝播を書かなくても微分できる**という
  大きな利点がある。融合カーネルは後から差し替えられるように、
  インターフェース（入出力の形と dtype）だけを固定している。

* **数値の安定性を層の中で解決する。**
  `softmaxCrossEntropy` は log-softmax を経由し、
  `binaryCrossEntropyWithLogits` は log-sum-exp の形で計算する。
  これは「勾配が層の外に出てから爆発する」のを避けるためで、
  前向きの数値が安定であれば VJP の再計算も安定になる。

* **`dropout` は反転ドロップアウト。** 学習時に `1/(1-p)` でスケールするので、
  推論時は恒等（`x` をそのまま返す）。**推論時の `dropout` は新しい参照を作らない**
  — かつて `x.retain()` を返していて、スコープの中では誰も解放しない参照になった。

* **`oneHot` は整数添字なので勾配を持たない。** マスクを作って書き込むだけで、
  autodiff の対象にはならない（`requires_grad` が立たない）。

* **層はすべて `ops` の上に乗っている。** だからそのまま `grad` で微分でき、
  `jit` でトレースもできる。`nn` の中に専用の逆伝播コードは 1 行も無い。

## 注意

* すべての層は「スコープが所有する」規則に従う。`nn.*` の戻り値を
  自分で `deinit` しない（`vmap` や `grad` の戻り値とはここが違う）。
* `maxPool2d` / `avgPool2d` は窓が空間次元を割り切れる必要がある
  （端数はエラー。padding つきの pooling は未実装）。
* `conv2d` の NCHW は `(batch, channel, height, width)`、カーネルは
  `(out_channel, in_channel, kh, kw)`。
