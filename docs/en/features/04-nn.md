# Neural network layers (`nn`)

## Usage

```zig
// layers
const h = try zpu.nn.dense(x, w, b);                     // x @ w + b
const n = try zpu.nn.layerNorm(x, scale, bias, 1e-5, -1);
const r = try zpu.nn.rmsNorm(x, scale, 1e-5, -1);
const a = try zpu.nn.gelu(x);                            // silu / leakyRelu / relu ...
const s = try zpu.nn.softmax(x, -1);
const e = try zpu.nn.embedding(table, ids);

// losses
const l1 = try zpu.nn.mse(pred, target);
const l2 = try zpu.nn.softmaxCrossEntropy(logits, one_hot_labels);
const l3 = try zpu.nn.sparseCrossEntropy(logits, class_index);
const l4 = try zpu.nn.binaryCrossEntropyWithLogits(logits, target);

// images
const c = try zpu.nn.conv2d(x, kernel, 1, 1);            // NCHW, stride, padding
const p = try zpu.nn.maxPool2d(x, 2);
const q = try zpu.nn.avgPool2d(x, 2);
const idx = try zpu.nn.oneHot(classes, depth, .f32);

// stochastic layers (training=false is the identity)
var gen = zpu.rng.Rng.init(42);
const d = try zpu.nn.dropout(x, 0.5, &gen, training);
```

## Implementation intent

* **Composition over kernels.** `conv2d` is `pad` → `sliceRanges` (the stride
  decimation) → `reshape` → `transpose` → `matmul`. It is measurably slower than
  a fused kernel, but it is differentiable *without writing a backward pass*, and
  the interface (shapes and dtypes) is frozen so a fused version can replace it
  later without touching any user code.

* **Numerical stability is the layer's job.** `softmaxCrossEntropy` goes through
  log-softmax and `binaryCrossEntropyWithLogits` uses the log-sum-exp form. The
  goal is that the gradients a layer emits are already well scaled, because the
  VJPs recompute whatever they need from the forward values.

* **`dropout` is inverted dropout.** It scales by `1/(1-p)` while training, so
  inference is the identity: it returns `x` itself and **takes no new
  reference**. Returning `x.retain()` was a real leak once — inside a scope
  nobody would have released it.

* **`oneHot` has no gradient.** It produces integer-shaped indicator data, so it
  never sets `requires_grad`; the mask is just written into a fresh tensor.

* **Everything sits on `ops`.** There is not a single line of hand written
  backward code in `nn`: layers differentiate, trace and vectorise because the
  primitives underneath do.

## Notes

* Layers follow the "the scope owns it" rule: do **not** `deinit` the result of
  an `nn.*` call (unlike `grad` / `vmap` results).
* `maxPool2d` / `avgPool2d` need the window to divide the spatial axes exactly;
  fractional edges are an error (padded pooling is not implemented).
* `conv2d` is NCHW: `(batch, channel, height, width)`, with kernels shaped
  `(out_channel, in_channel, kh, kw)`.
