# ZAPP 開発ロードマップ

## 現在の課題

1. **文字レンダリング** - フォントデータが簡易的なため、文字が判読しにくい
2. **座標系の分離** - 実ピクセルと仮想ピクセルが混在している

## 技術的決定

### 座標系の設計
```zig
// 論理座標（レイアウト計算用）
const VirtualRect = struct {
    x: f32, y: f32, w: f32, h: f32
};

// 実ピクセル（レンダリング用）
const PhysicalRect = struct {
    x: u32, y: u32, w: u32, h: u32
};

// スケーリング
const scale: f32 = physical_width / virtual_width;
```

### ECSの選択肢
1. **hecs** - Rust製、軽量
2. **flecs** - C/C++製、高機能
3. **Zigネイティブ実装** - 依存関係なし、最適化可能
