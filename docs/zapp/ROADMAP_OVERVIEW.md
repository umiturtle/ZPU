# ZAPP ロードマップ（高レベル版）

## プロジェクトビジョン

Zigエコシステムに**現代的で高速、かつカスタマイズ性の高いUIフレームワーク**をもたらす。

---

## 方向性

### コアバリュー
1. **パフォーマンス** - 120FPS、可変リフレッシュレート、ゼロGC
2. **開発者体験** - ホットリロード、型安全、IDEサポート
3. **国際化** - 日本語を含む多言語対応
4. **カスタマイズ性** - テーマ、レイアウト、動作をユーザーが制御
5. **プラットフォーム中立** - ネイティブ + Web

### デザイン方針
- **新鮮さと使いやすさの両立**
  - 最新トレンドを取り入れつつ、直感的な操作感を維持
  - 過去（マテリアル/ミニマル）に囚われない
  - カスタマイズ可能：ユーザーが「新鮮さ」と「慣れ親しみ」を選択
- **最終目標：完全なカスタマイズ性**
  - テーマシステム（色、タイポグラフィ、形状、動き）
  - レイアウトのカスタマイズ
  - コンポーネントの拡張・差し替え

## フェーズ構成

### Phase 0: 開発基盤
**目的**: 安全に開発を続けられる基盤を作る
- CI/CDパイプライン
- スナップショットテスト
- コード品質管理

### Phase 0.5: デザインリサーチ
**目的**: 方向性を確定し、手戻りを防ぐ
- 現代的UIの調査（Linear, Vercel, Raycast, Arc等）
- デザイントークン定義
- 「新鮮さ」と「使いやすさ」の両立方法の検討
- カスタマイズ性の設計

### Phase 1: 基盤整備
**目的**: 全ての機能の土台を作る
- 座標系の分離（仮想/物理）
- フォントシステム（多言語対応基盤）
- モジュールの疎結合化

### Phase 2: パフォーマンス
**目的**: コアバリュー（高速さ）を実現
- 120FPSレンダリング
- 可変リフレッシュレート対応
- 可変ウィンドウサイズ対応
- レンダリング最適化

### Phase 3: インタラクションとi18n
**目的**: ユーザーが実際に使える状態にする
- 日本語入力（IME対応）
- テキスト編集機能
- キーボード/マウス/タッチ入力

### Phase 4: 開発者体験
**目的**: 開発効率を最大化
- ホットリロード
- デベロッパーツール（インスペクタ、プロファイラ）
- API改善、IDEサポート

### Phase 5: アーキテクチャ
**目的**: 将来の拡張性を確保
- ECS移行検討
- レスポンシブレイアウト
- 状態管理

### Phase 6: Web連携
**目的**: プラットフォームを拡大
- WASM対応
- ブラウザへの処理委譲（テキストレンダリング等）
- ハイブリッドレンダリング

### Phase 7: アクセシビリティ
**目的**: 誰もが使えるUIにする
- WCAG準拠
- スクリーンリーダー対応
- キーボードナビゲーション

### Phase 8: ウィジェット拡充
**目的**: 実用的なアプリケーションを構築可能に
- 基本ウィジェット完成
- 高度なウィジェット
- アニメーション

### Phase 9: カスタマイズシステム
**目的**: ユーザーが自由にUIを制御できるように
- テーマシステム（完全カスタマイズ）
- プラグイン/拡張機能
- コンポーネントの差し替え

### Phase 10: 配布とエコシステム
**目的**: プロダクションレディにする
- パッケージング
- ドキュメント整備
- サンプルアプリケーション
- コミュニティ構築

### Phase 11: エンタープライズ対応
**目的**: 組織での利用を可能に
- セキュリティ
- 権限管理
- 監査ログ
- サポート契約

### Phase 12: 持続的改善
**目的**: 長期的な成長を確保
- パフォーマンスベンチマーク
- リグレッションテスト
- ユーザーフィードバック収集
- 定期的なアップデート

## リスク

- Zigコンパイラの不安定さ
- WASMの制約
- パフォーマンス目標未達
- 日本語入力の複雑さ
- カスタマイズ性とパフォーマンスのトレードオフ

---

## 成功基準

### 定量的
- 120FPS維持（標準UIで）
- 日本語入力スムーズ動作
- ホットリロード <500ms
- テストカバレッジ 80%以上
- WCAG AA準拠

### 定性的
- 「Zigらしい」UI
- 新規開発者が1日でサンプルを動かせる
- 新鮮さと使いやすさの両立
- 高いカスタマイズ性
