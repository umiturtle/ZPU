# スナップショット仕様 — 何が正しいレンダリング結果か

各スクリーンショットが「正しい」と判定される条件を定義する。

## snapshots/zapp/resize/ — リサイズ一貫性テスト

`zig build run-resize-test` で生成される10枚のPPM。
全解像度（100x100〜3840x2160）で**同じパターン**が描画されていること。

### 各ピクセルの仕様

```
┌─────────────────────────────────────────┐
│  赤い枠線 (R=255, G=0, B=0)             │ ← 上下左右1px
├─────────────────────────────────────────┤
│                                         │
│  背景: RGB グラデーション               │
│    R = x / width                        │
│    G = y / height                       │
│    B = 1.0 - (R + G) / 2.0              │
│                                         │
│     黄色の対角線（X字）                 │
│     左上→右下、右上→左下                │
│                                         │
│         中央に白のチェッカー            │
│         画像の中央1/2 x 中央1/2 領域    │
│         チェックサイズ = max(w/20, 10)  │
│                                         │
│        中央に緑の十字                   │
│        y = height/2, x = width/2        │
│                                         │
└─────────────────────────────────────────┘
```

### 検証ポイント

1. **サイズ**: ファイル名の解像度とPPMヘッダーが一致
2. **枠線**: 外周1pxが赤（R=255, G=0, B=0）
3. **グラデーション**: 左上が青み、右下が赤み
4. **対角線**: 黄色（R=255, G=255, B=0）のX字
5. **十字**: 緑（R=0, G=255, B=0）の水平・垂直線
6. **チェッカー**: 中央領域の白・透明交互パターン
7. **クロス環境一貫性**: Linux X11 と Web (Wasm) で同一パターン

2. **ウィジェット背景**: やや明るいグレー (R≈0.2, G≈0.2, B≈0.25)
3. **テキスト**: 白 (R≈0.9)
4. **ボーダー**: 中グレー (R≈0.4)

7. **スペーシング**: padding=16, spacing=8 の場合、ウィジェット間に8px

## 判定基準

### ピクセル完全一致テスト（将来用）

```
各ピクセルの差分 <= 1/255 (約0.004) → PASS
平均差分 <= 0.001 → PASS
構造的類似度 (SSIM) >= 0.99 → PASS
```

### 色チェック

| 要素 | 期待値 (sRGB 0-1) |
|------|------------------|
| 背景 | (0.12, 0.12, 0.16) |
| テキスト | (0.9, 0.9, 0.9) |
| ボーダー | (0.4, 0.4, 0.4) |
| アクセント | (0.3, 0.6, 0.9) |
| 赤枠（resize） | (1.0, 0.0, 0.0) |
| 緑十字（resize） | (0.0, 1.0, 0.0) |
| 黄色対角線（resize） | (1.0, 1.0, 0.0) |
